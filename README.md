# Republic of Limoria — Full 3D Enhanced Website

A cinematic fictional-country website with an interactive Three.js globe.

## Highlights
- 17 responsive pages
- Interactive 3D globe with lights, stars and wireframe
- Pointer-reactive scene
- Glassmorphism interface and 3D tilt cards
- Cursor glow and reading progress bar
- Mobile navigation
- Keyboard shortcuts: H = home, / = navigation
- Enhanced home-page 3D atlas section
- GitHub Pages ready
- All country facts, institutions, places and events are fictional

Upload the contents to `RepublicLimoria.github.io` and enable GitHub Pages from `main` / `(root)`.

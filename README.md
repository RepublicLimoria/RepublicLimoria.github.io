# Republic of Limoria

A cinematic fictional-country website built for worldbuilding, design and creative storytelling.

## Site structure

- Root HTML pages: the public Limoria sections, including the Presidency.
- `assets/css/`: shared visual system and 3D styling.
- `assets/js/`: navigation, scroll effects, service-worker registration and Three.js scene.
- `assets/img/`: logo, flag, hero and favicon artwork.
- `manifest.webmanifest`: installable web-app metadata.
- `sw.js`: offline caching for the core experience.
- `sitemap.xml` and `robots.txt`: search-engine discovery files.

## Design direction

The interface uses Limoria's navy, green and gold palette with responsive cards, a cinematic hero, subtle 3D motion, accessible focus states and reduced-motion support.

> Limoria, its institutions, laws, statistics, offices and services are fictional and created for this project.

## Deployment

This repository is configured for GitHub Pages from the `main` branch and repository root.

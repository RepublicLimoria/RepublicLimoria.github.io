# Republic of Limoria — Full 3D Enhanced Website

A cinematic fictional-country website with an interactive Three.js globe.

## Highlights
- 17 responsive pages
- Interactive 3D globe with lights, stars and wireframe
- Pointer-reactive scene
- Glassmorphism interface and 3D tilt cards
- Cursor glow and reading progress bar
- Mobile navigation
- Keyboard shortcuts: H = home, / = navigation
- Enhanced home-page 3D atlas section
- GitHub Pages ready
- All country facts, institutions, places and events are fictional

Upload the contents to `RepublicLimoria.github.io` and enable GitHub Pages from `main` / `(root)`.


Updated fictional country profile: President Limon; population 0; area 0 km². A supplied portrait is included at assets/img/president.png.


Language: The header includes a Bangla / English toggle. The selected language is remembered in the browser.


## PWA
This site is installable as a phone app. It includes a web app manifest, 192/512 icons, standalone display, splash screen, service-worker offline caching for previously visited pages/assets, and automatic service-worker updates when a new version is deployed.


### SEO, accessibility & performance
- Open Graph/Twitter metadata, canonical URLs, robots.txt and sitemap.xml configured for https://RepublicLimoria.github.io/.
- Skip link, keyboard focus states and reduced-motion support included.
- President image compressed for faster loading.
- The visitor counter is privacy-friendly and device-local; a global counter requires a backend/analytics service.
- iOS standalone/PWA metadata and Apple touch icon included.
